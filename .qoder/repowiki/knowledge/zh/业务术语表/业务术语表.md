### 预取模式
- 定义：Worker 池的一种运行方式：通过 `TaskPrefetcher` 提前从共享队列批量拉取任务 ID 到本地内存队列，worker 直接从本地队列消费，以降低跨进程/跨节点网络往返开销。与“直接模式”相对，后者每次 pop 都访问共享队列。
- 别名：prefetch mode、预取器

### 看门狗
- 定义：为分布式锁自动续期的后台协程，按 TTL 的一定比例周期调用锁的 extend 接口，防止长任务执行期间锁过期被其他节点抢占。由 `WatchDog` 实现，配合 `LockManager` 的 `auto_extend` 开关使用。
- 别名：watchdog、锁续期

### 僵尸锁
- 定义：因持有锁的节点崩溃或异常退出而未能释放的锁，TTL 已过期但仍占用键空间。由 `LockScanner` 定期扫描并清理，也可由 `TaskReclaimer` 在回收任务时一并处理。
- 别名：stale lock

### 孤儿任务
- 定义：处于 RUNNING 状态但所属 worker 节点已不可用的任务，通常由节点宕机导致。回收器会将其重新入队重试或直接标记失败。
- 别名：orphan task

### 死信队列
- 定义：存放最终失败（超过最大重试次数）任务的独立存储，保留原始任务数据、失败原因与错误堆栈，供人工排查或后续重放。本项目的死信条目使用 Redis List + Hash 索引持久化。
- 别名：DLQ、dead letter queue

### 任务回收器
- 定义：周期性扫描并处理超时任务、孤儿任务与僵尸锁的后台组件，根据策略选择重试入队或标记失败，同时释放关联锁。内部组合了 `LockScanner` 完成锁扫描。
- 别名：reclaimer、TaskReclaimer

### 延迟队列
- 定义：用于调度在未来某个时间点才进入可执行状态的队列，内部使用时间堆（heapq）维护到期顺序，到期后回调将任务推入优先级队列等待消费。
- 别名：delayed queue

### 队列调度器
- 定义：Facade 层，统一封装优先级队列与延迟队列，对外提供 push/pop/remove 等接口，并根据 delay 参数决定入哪条队列；同时支持暂停/禁用控制。
- 别名：QueueScheduler
