本仓库不包含独立的 CSS/SCSS/Tailwind 等前端样式工程，Web UI 仅由一个内嵌在 `src/neotask/web/static/index.html` 的单文件 Dashboard 构成。该页面采用“HTML + 内联 `<style>` + 内联 `<script>`”的极简模式：
- 样式全部写在 `<head>` 中的 `<style>` 块里，使用原生 CSS（BEM 风格类名如 `.navbar`、`.stat-card`、`.status-success`），未引入任何第三方 UI 框架或 CSS 预处理工具。
- 主题色为深色系（背景 `#0f172a` → `#1e293b` 渐变，卡片半透明 `rgba(30,41,59,0.6)` + `backdrop-filter: blur(10px)`），强调色使用 Tailwind 风格的蓝紫色阶（`#3b82f6`、`#8b5cf6`、`#60a5fa`），状态色沿用 `#22c55e`（成功）、`#ef4444`（失败）等。
- 响应式通过一条 `@media (max-width: 768px)` 媒体查询实现，布局基于 CSS Grid（`.stats-grid`）与 Flexbox，无断点体系。
- 交互逻辑（WebSocket 连接、统计更新、任务列表渲染、取消任务等）同样内联在页面底部的 `<script>` 中，未拆分为模块。

结论：本项目没有建立可复用的前端样式体系（无设计令牌、组件库、构建管线），所有视觉呈现都集中在单一 HTML 文件中，属于最小可用的内置 WebUI 方案。若需扩展 UI，应遵循当前“单文件内联”约定，或将样式/脚本逐步抽离为独立资源文件。
