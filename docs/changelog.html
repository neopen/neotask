更新日志

NeoTask 的真实发布记录。每个版本都对应 PyPI 发布与 GitHub Release，升级前请阅读当前版本的修复说明。

在 PyPI 安装 v1.0.5 GitHub Releases
最新版本 v1.0.5 发布日期 2026-10-29 许可证 MIT Python 3.8+

升级建议

生产环境建议使用最新补丁版本。从 1.0.2 起依赖收敛到少量基础库；当前 1.0.5 基础依赖为 aiosqlite、croniter 与 colorama，最低支持 Python 3.8+。

pip install -U neotask

订阅更新

在 GitHub 仓库选择 Watch → Releases，即可在每次发布时收到通知。
