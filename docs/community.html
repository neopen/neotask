编辑文档

本地开发

克隆仓库，以可编辑模式安装开发依赖，然后运行测试。

  • Python 3.8+
  • 测试使用 pytest
  • 建议按模块运行相关测试
terminal 
# 克隆并安装开发依赖
git clone https://github.com/neopen/neotask.git
cd neotask
pip install -e ".[dev]"

# 运行全部测试
pytest tests/

# 运行单个模块
pytest tests/test_task_pool.py -v

Pull Request 流程

  1. 01
    Fork 并创建分支

    从 main 创建聚焦的特性或修复分支。

  2. 02
    补充测试

    行为变更应附带可复现的测试用例，确保既有测试通过。

  3. 03
    保持改动聚焦

    一个 PR 解决一个问题，避免混入无关格式化。

  4. 04
    描述变更与影响

    说明动机、行为差异与升级注意事项。

  5. 05
    根据评审迭代

    讨论达成一致后合并，并进入下一个发布周期。
