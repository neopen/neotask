Local development

Clone the repository, install the development dependencies in editable mode, then run the tests.

  • Python 3.8+
  • Tests use pytest
  • Run the tests for the module you touched
terminal 
# Clone and install development dependencies
git clone https://github.com/neopen/neotask.git
cd neotask
pip install -e ".[dev]"

# Run the full test suite
pytest tests/

# Run a single module
pytest tests/test_task_pool.py -v

Pull request workflow

  1. 01
    Fork and branch

    Create a focused feature or fix branch from main.

  2. 02
    Add tests

    Behavior changes should ship a reproducible test case; keep existing tests green.

  3. 03
    Keep the change focused

    One pull request solves one problem; avoid unrelated formatting noise.

  4. 04
    Describe the change and its impact

    Explain the motivation, behavioral differences and upgrade notes.

  5. 05
    Iterate through review

    Merge once the discussion converges; the change ships in the next release cycle.
