Cost and timing

Report tokens, API calls, and estimated cost; read queue/execution timing and aggregate costs.

v1.0 · NeoTask 1.x Updated 2026-11-22 6 min read GitHub

Since 1.1, task records keep execution duration and business cost. NeoTask computes duration automatically; cost requires the executor to report tokens, API call counts and estimated charges. NeoTask only accumulates and queries — it does not price, bill or reconcile.

Automatic duration fields

FieldHow it is computedWhen it is written
queue_wait_msstarted_at - created_atWhen the task starts running
duration_mscompleted_at - started_atOn entering a terminal state

Both fields appear in the return values of get_result() and get_task(). Timing restarts when a task is retried and the previous round's values are overwritten; cost behaves the opposite way, with consumption from every run accumulating.

Report cost

from neotask import report_cost

async def llm_task(data):
    response = await call_model(data["prompt"])
    report_cost(
        tokens_in=120,
        tokens_out=48,
        api_calls=1,
        estimated_cost=0.0012,
        currency="USD",
    )
    return {"text": response}

report_cost() is a synchronous function: call it directly from async tasks and from sync tasks running in a thread, with no await. The process executor has no such context, so call pool.report_cost(task_id, ...) from the parent process instead.

ParameterDefaultNotes
tokens_in / tokens_out0Input and output token counts, accumulated
api_calls0Number of external API calls, accumulated
estimated_costNoneCharge for this report; when None only the other fields are accumulated
currencyNoneCurrency identifier, such as USD
  • Repeated reports accumulate per field. estimated_cost in the task record is the total, while cost_tracking keeps the breakdown and the currency.
  • The currency is fixed by the first report; if a task reports different currencies it is marked MIXED, so amounts in different currencies are never silently summed.
  • Terminal tasks still accept additional cost, which suits the case where the parent process only receives usage data after a child task finishes.
  • Reporting inside an executor returns bool; outside a task context (such as a process executor) it returns False.

Aggregate queries

summary = pool.get_cost_summary(child_ids)
print(summary)
# {
#   "task_count": 20, "tasks_with_cost": 18,
#   "tokens_in": 2400, "tokens_out": 960,
#   "api_calls": 20, "estimated_cost": 0.024, "currency": "USD"
# }

total = pool.get_cost_summary()   # aggregates all tasks when task_ids=None
FieldNotes
task_countNumber of tasks included in the aggregation
tasks_with_costNumber of tasks with at least one cost record
tokens_in / tokens_out / api_callsAccumulated breakdown values
estimated_costAccumulated amount; a float, not suitable for financial settlement
currencyA single currency, an empty string, or MIXED

Aggregation happens in the storage layer; task records are not read into the process one by one. IDs in task_ids that do not exist are ignored rather than raising an error.

Cost events

async def on_cost(event):
    print(event.task_id, event.data)
    # {"tokens_in": 120, "tokens_out": 48, "api_calls": 1,
    #  "estimated_cost": 0.0012, "currency": "USD"}

pool.event_bus.subscribe("task.cost_reported", on_cost)

The task.cost_reported payload is the breakdown of this report, not a cumulative total. event.data contains only the fields passed in this call; if currency was omitted the key is absent. The event has no dedicated convenience method; subscribe with event_bus.subscribe().

Boundaries

  • Cost is supplied entirely by the caller. NeoTask does not parse model pricing and does not validate the unit of an amount.
  • Cost from retries and manual retries is kept and accumulated; a task that ultimately fails does not lose the consumption already recorded.
  • Terminal cleanup deletes cost details together with the task; for long-term cost reporting, aggregate periodically and archive externally.
  • Events may be dropped by the bounded queue, so treat the stored result of get_cost_summary() as authoritative for cost totals.
