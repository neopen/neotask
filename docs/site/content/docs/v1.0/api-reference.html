公开入口为 TaskPool 与 TaskScheduler。除特别标注外，每个同步方法都有一个同名的 _async 版本，参数与返回值一致。

from neotask import TaskPool, TaskScheduler, TaskPoolConfig, SchedulerConfig

TaskPool

TaskPool(executor=None, config=None)

executor 可以是普通函数、协程函数或 TaskExecutor 实例；为 None 时使用返回固定结果的默认执行器。

生命周期与提交

方法说明
start()显式启动；首次提交也会自动启动
shutdown(graceful=True, timeout=30)停止接收新任务，等待队列清空后关闭
submit(data, task_id=None, priority=NORMAL, delay=0, ttl=3600)提交任务，返回任务 ID
submit_batch(tasks, priority=NORMAL)逐条提交任务列表，返回 ID 列表
create_pending_task(data, task_id=None, priority=NORMAL, ttl=3600)只创建记录，不入队
enqueue_task(task_id)把 pending 任务入队；非 pending 返回 False

等待与查询

方法说明
wait_for_result(task_id, timeout=300)等待并返回结果；失败、取消或超时抛异常
wait_all(task_ids, timeout=300)逐项等待，返回 {task_id: result}
get_status(task_id)状态字符串或 None
get_result(task_id)结果摘要字典或 None
get_task(task_id)完整任务字典或 None
task_exists(task_id)任务是否存在

任务管理

方法说明
cancel(task_id)移除队列项并置为 cancelled；仅 pending / running 有效
retry(task_id, delay=0)重置终态任务并重新入队
delete(task_id)删除任务记录
pause() / resume()暂停 / 恢复出队，仍可继续入队
clear_queue()清空队列；不修改已创建的任务记录

统计与健康

方法说明
get_stats()队列、任务计数、指标、回收与预取摘要
get_worker_stats()各 Worker 的忙碌状态与计数
get_health_status()存储、队列、系统健康检查；缓存 5 秒
get_queue_size()优先队列与延时队列总数

锁与节点

方法说明
acquire_lock(task_id, ttl=30)获取 task:{task_id} 锁
release_lock(task_id)释放本实例持有的锁
get_active_nodes()Redis 模式下的活跃节点列表
is_leader()始终返回 False

事件

方法事件
on_created(handler)task.created
on_started(handler)task.started
on_completed(handler)task.completed
on_failed(handler)task.failed
on_cancelled(handler)task.cancelled
on_progress(handler)task.progress
on_reclaimed(handler)task.reclaimed

TaskScheduler

TaskScheduler(executor=None, config=None)

内部创建一个 TaskPool，并增加延时、周期与 Cron 调度。以下方法除 get_periodic_* 等同步专用项外，同样存在 _async 版本。

延时任务

方法说明
submit_delayed(data, delay_seconds, task_id=None, priority=NORMAL, ttl=3600)延迟执行一次
submit_at(data, execute_at, task_id=None, priority=NORMAL, ttl=3600)在指定时间执行一次

周期任务

方法说明
submit_interval(data, interval_seconds, task_id=None, priority=NORMAL, run_immediately=True, max_runs=None, name="", missed_policy=None)固定间隔执行
submit_cron(data, cron_expr, task_id=None, priority=NORMAL, max_runs=None, name="", missed_policy=None)Cron 表达式执行
get_periodic_tasks()列出周期任务
get_periodic_task(task_id)查询单个周期任务
pause_periodic(task_id)暂停周期任务
resume_periodic(task_id)恢复周期任务
cancel_periodic(task_id)删除周期任务

委托给 TaskPool 的方法

方法说明
submit(...) / submit_async(...)同 TaskPool
wait_for_result(...)同 TaskPool
get_status / get_result / get_task / task_exists同 TaskPool
cancel / delete / retry先尝试周期任务，再操作普通任务
get_stats / get_queue_size / get_health_status汇总周期与时间轮统计
pause / resume / clear_queue同 TaskPool
on_created 等 6 个回调同 TaskPool；无 on_reclaimed

返回值语义

方法成功失败 / 不存在
submit*任务 ID 字符串队列满抛 QueueFullError；ID 重复抛 TaskAlreadyExistsError
wait_for_result执行器返回值抛异常；超时抛 TimeoutError
get_status / get_result / get_task对应数据None
cancel / retry / deleteTrueFalse

异常

异常触发场景
TaskSchedulerError所有异常的基类
TaskNotFoundError等待不存在的任务
TaskAlreadyExistsError使用已存在的 task_id 提交
QueueFullError队列达到 queue_max_size
TimeoutErrorwait_for_result 超时
TaskError已定义但当前版本未使用
