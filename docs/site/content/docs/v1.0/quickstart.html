NeoTask 1.0 提供两个入口：TaskPool 负责即时任务，TaskScheduler 负责任务的延时与周期调度。两者执行模型相同：你提供一个可调用对象，NeoTask 负责排队、并发执行、状态记录与结果回传。

提交第一个任务

执行器接收一个 dict，返回值会作为任务结果保存。返回值必须可 JSON 序列化。

import asyncio
from neotask import TaskPool

async def handle(data):
    await asyncio.sleep(0.1)
    return {"value": data["value"] * 2}

pool = TaskPool(executor=handle)
task_id = pool.submit({"value": 21})
result = pool.wait_for_result(task_id)
print(result)  # {'value': 42}
pool.shutdown()

TaskPool 首次提交时会自动启动，也可以显式调用 pool.start()。

三种调用方式

方式适用场景示例
同步 API脚本、普通函数、需要立即拿结果submit() + wait_for_result()
异步 API已在事件循环中的服务await submit_async() + await wait_for_result_async()
上下文管理器需要确保资源释放with TaskPool(...) as pool:
 
# 异步
task_id = await pool.submit_async({"value": 1})
result = await pool.wait_for_result_async(task_id, timeout=30)

# 同步上下文管理器
with TaskPool(executor=handle) as pool:
    task_id = pool.submit({"value": 2})
    print(pool.wait_for_result(task_id))

# 异步上下文管理器
async with TaskPool(executor=handle) as pool:
    task_id = await pool.submit_async({"value": 3})
    print(await pool.wait_for_result_async(task_id))

只提交，不等待

后台任务通常不需要等待结果。提交后通过任务 ID 查询状态或结果：

task_id = pool.submit({"value": 5})
pool.get_status(task_id)   # pending / running / success / failed / cancelled
pool.get_result(task_id)   # 包含 status、result、error、时间戳

# 需要时可阻塞等待
result = pool.wait_for_result(task_id, timeout=60)

批量提交

task_ids = pool.submit_batch([{"value": i} for i in range(100)])
results = pool.wait_all(task_ids, timeout=60)
# {task_id: result}；失败任务的值形如 {"error": "..."}

常见错误

现象常见原因处理
ModuleNotFoundError: neotask安装到了另一个 Python 或虚拟环境确认 python -m pip 与运行解释器一致，重新安装
Redis 连接失败未安装 redis 扩展或地址不可达安装 neotask[redis]，检查 redis_url 与网络
任务一直 pending池未启动、并发为 0 或 Worker 异常显式调用 pool.start()，用 get_stats() 查看队列与 Worker 状态
wait_for_result 超时任务仍在执行，或同步阻塞函数占住了事件循环调大等待时间；阻塞代码改用 ThreadExecutor
database is lockedSQLite 被多个写入者并发访问保持单写入者，或改用 Redis
