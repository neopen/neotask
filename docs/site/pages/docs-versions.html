版本策略

版本对应

文档版本对应 NeoTask 的次版本线。例如 v1.0 文档适用于 1.0.x，缺陷修复不会改变文档路径。

链接稳定

已发布版本的文档链接保持不变；新版本在独立路径下发布，不会覆盖旧版内容。

升级前核对

跨次版本升级时，请同时阅读新旧两版文档的配置参考与 API 参考，确认参数和行为变化。

找不到对应版本？

旧版本文档会随版本发布持续保留。如果需要更早版本或迁移帮助，请在 GitHub Issues 中说明使用的版本。
