Upgrade advice

Production should run the latest patch release. Since 1.0.2 dependencies are limited to a small set of base libraries; the current {{VERSION}} baseline depends on aiosqlite, croniter and colorama, and supports Python {{PYTHON}}. Since 1.0.8, neotask --benchmark provides a lightweight performance self-check; 1.1 added checkpoint resume, cost tracking and business failure reporting; 1.2 adds monitoring snapshots and periodic push; 1.2.1 fixes prefetch idle backoff, in-memory batch writes and Redis batch reads.
