Version policy

One docs line for 1.x

The v1.0 line covers the entire 1.x series, currently baseline {{LATEST_BASELINE}}. 1.x ships compatible enhancements only, so patch and minor releases never change documentation paths.

Stable links

Links for a published version stay fixed. Version 2.0 adds its own docs line under a separate path and does not overwrite older content.

Check before upgrading

When moving from 1.x to 2.0, read both the old and new configuration and API references and confirm the breaking changes.

Can't find your version?

Docs are kept per major version line. If you need an older release or migration help, tell us which version you run in GitHub Issues.
